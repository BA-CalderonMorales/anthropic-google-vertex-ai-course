# anthropic-google-vertex-ai-course

Using this to help keep me on track with completing this course: https://anthropic.skilljar.com/claude-with-google-vertex, feel free to fork and leverage the pattern for yourself.

This repository is **not** an answer key. It is a lightweight structure for organizing study notes, experiments, and implementation practice while moving through the course.

Start here:
- [docs/](docs/) for section-by-section notes
- [notebooks/](notebooks/) for Colab-first hands-on work

```text
.
├── docs/
│   ├── index.md                        # Notes hub and section links
│   ├── README.md                       # How docs are organized
│   └── {section}/README.md             # Notes page for each core section
├── notebooks/
│   ├── README.md                       # Notebook workflow and naming guidance
│   ├── config/                         # Shared notebook config/templates
│   └── {section}/workbook.ipynb        # One Colab-ready notebook per core section
└── README.md                           # Repo scope + map
```
